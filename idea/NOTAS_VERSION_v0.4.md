# Notas de versión v0.4 — Docentes + innovación + evidencia costarricense

**Corte de información:** 22-11-2026. **Naturaleza:** suite de contexto, investigación y diseño; no es software funcional.

## Adiciones principales
- Núcleo pedagógico reescrito como sistema de coelaboración, conversación, decisiones y memoria contextual.
- Casos recuperados con límites de procedencia (Geometrópolis, tren STEAM, taller, Pasaporte de Misión).
- Investigaciones en fuentes primarias TEC/INNOVA-MatIA y libro completo (Seis R, cuatro roles, curaduría).
- UCR: gobernanza 2026, formación docente/Metics, primaria, proyectos de coautoría y formación continua.
- MEP: guía IA, circular 2026, Anexo A, autoría/redacción personal docente, competencias y particularidades de adecuación.
- Mercado: Ociann Class como competidor local que sí anuncia adaptación MEP; público/privado con requisitos verificables.
- Evidencia EEF/NFER 2024–2026, límites y pilotos propios.
- Inspiración Claude for Teachers, Brisk, MagicSchool, Khanmigo, Curipod, Aila con criterio crítico.
- Arquitectura modelo-agnóstica, agentes, groupbots, workflows, sandboxes, privacidad y métricas.
- Suite anterior v0.3 preservada como histórico en `historico/v03/`.

## Correcciones importantes
No decir «a los docentes no se les permite usar IA»: la circular enfatiza autoría y responsabilidad personal; la interpretación funcional debe validarse jurídicamente. No decir «ningún competidor se alinea al MEP»: Ociann Class lo afirma. No decir «privados no siguen MEP»: sus ofertas y acreditación están reguladas. No decir «el libro TEC prueba la demanda de pago»: documenta interés y formación, no disposición a pagar.
